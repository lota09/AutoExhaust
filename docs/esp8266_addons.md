# ESP8266 (Wemos D1 R1) 잠재력 활용 가이드 🚀

AutoExhaust 프로젝트를 넘어, 서랍 속의 Wemos D1 R1 보드를 100% 활용하기 위한 핵심 기능과 확장 아이디어를 정리합니다.

---

## 1. 뼈 속까지 활용하는 3대 핵심 기능

### 📡 OTA (Over-The-Air) 무선 업데이트
*   **개요**: USB 케이블 없이 WiFi 네트워크를 통해 펌웨어를 업로드하는 기술입니다.
*   **활용**: 프린터 내부에 보드가 이미 매립된 경우, 뜯지 않고 거실에서 소스 코드를 수정하고 업로드할 수 있습니다.
*   **라이브러리**: `ArduinoOTA`

### 📂 LittleFS (내부 파일 시스템)
*   **개요**: 4MB 플래시 메모리 중 일부를 저장공간으로 활용합니다.
*   **활용**:
    *   **영구 설정**: WiFi SSID나 MQTT 정보를 파일에 저장하여, 소스 코드 수정 없이 변경 가능.
    *   **오프라인 로그**: 리셋 직전의 에러 메시지를 `error.txt`에 기록하여 사후 분석.

### 🌐 mDNS (Multicast DNS)
*   **개요**: 복잡한 IP 주소(`192.168.0.x`) 대신 이름을 부여합니다.
*   **활용**: 브라우저나 앱에서 `http://exhaust.local`로 접속 가능. IP가 바뀌어도 주소는 그대로 유지됩니다.

## 2. 하드웨어 확장 (Peripheral) 아이디어

### 📺 I2C Status OLED (D1, D2 핀)
*   **부품**: 0.96인치 SSD1306 OLED (2~3천원)
*   **활용**: 프린터 본체 옆에 작은 화면을 달아 **현재 노즐 온도, 프린트 달성도(%), 팬 속도**를 실시간 표시. 시리얼 모니터가 필요 없는 독립 시스템 완성.

### 🌓 ADC 조도 센서 (A0 핀)
*   **부품**: CdS 광센서
*   **활용**: 주변이 밝을 때는 LED를 끄고, 어두운 야간 프린팅 시에만 조명을 켜도록 설계하여 전력 및 수명 관리.

### 🔔 상태 알림 스피커 (D8 핀)
*   **부품**: Active/Passive Buzzer
*   **활용**: 출력 종료 시 경쾌한 멜로디를 재생하거나, 비정상적인 온도 상승 시 물리적인 경고음 발생.

## 3. 전원 및 시스템 최적화 (Power Management)

### 💤 Deep Sleep & Wakeup (D0 - RST 연결)
*   **개요**: 칩의 전력 소비를 0.02mA 수준으로 낮추는 초절전 모드입니다.
*   **방법**: **D0(GPIO16)** 핀과 **RST** 핀을 점퍼 와이어로 연결하면, 설정된 시간이 지난 뒤 스스로를 깨울 수 있습니다.
*   **활용**: 장시간 출력이 없을 때 보드를 완전히 잠재웠다가, 특정 주기마다 깨어나 상태를 확인하게 하여 불필요한 전력 낭비와 발열을 차단합니다.

### 🔋 내부 VCC 감시 (ADC_VCC)
*   **개요**: 외부 부품 없이 칩으로 들어오는 공급 전압을 센싱합니다.
*   **방법**: 소스 코드 상단에 `ADC_MODE(ADC_VCC);`를 선언하고 `ESP.getVcc()`를 호출합니다.
*   **활용**: 벅 컨버터 출력 전압이 불안정해지거나(Drop), 전력 부족으로 리셋되기 직전의 전압 강하 상황을 감지하여 사용자에게 알람(MQTT 등)을 보낼 수 있습니다. (※ 주의: 이 기능을 쓰면 A0 핀의 외부 입력은 쓸 수 없습니다.)

---

## 4. 고급 네트워크 기능

### 🏠 로컬 웹 대시보드 (Web Server)
*   **설명**: ESP8266 내부에 HTML 페이지를 수록합니다.
*   **활용**: 스마트폰으로 접속하여 **LED 밝기를 슬라이더로 조절**하거나, 팬을 강제로 on/off 시키는 제어판을 구축합니다.

### 📩 Push 알림 (Webhook)
*   **설명**: 특정 상황 발생 시 외부 서버로 신호를 보냅니다.
*   **활용**: 출력이 완료되거나 에러가 발생하면 스마트폰(IFTTT, Telegram 등)으로 즉시 알림 메시지 발송.

---

## 🎯 100% 활용을 위한 로드맵 제안
1.  **Level 1**: `mDNS`와 `OTA`를 적용하여 '무선 개발 환경' 구축.
2.  **Level 2**: `VCC 감시`와 `LittleFS`를 적용하여 시스템의 '안전성과 영속성' 확보.
3.  **Level 3**: `Deep Sleep`을 이용한 '친환경 절전 로직' 구현.
4.  **Level 4**: `I2C OLED`를 달아 프린터 본체의 'Status 전광판' 완성.
