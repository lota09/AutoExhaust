# ESP8266 (Wemos D1 R1) 기술 분석 및 진행 보고서

Bambu Lab X1C 연동 시스템인 AutoExhaust를 ESP8266 환경으로 이식하며 달성한 성과와 기술적 최적화 내용을 정리합니다.

## 1. 프로젝트 개요
*   **목표**: ESP32 기반 시스템을 범용적인 ESP8266(Wemos D1 R1) 기반으로 마이그레이션.
*   **핵심 도전 과제**: 
    *   최신 WiFi 라우터와의 연결 안정성 확보.
    *   12.2KB에 달하는 뱀부랩 MQTT JSON 데이터 처리 (ESP8266의 램 한계 극복).
    *   SSL(MQTTS) 통신 시의 메모리 고갈 및 시스템 리셋 방지.

## 2. 주요 기술적 달성 사항

### 🚀 WiFi 연결 안정화 (Enhanced Mode)
최신 공유기(TUF-AX5400)의 Smart Connect 환경에서 자주 발생하던 연결 끊김 현상을 해결하였습니다.
*   **802.11g 고정**: `WiFi.setPhyMode(WIFI_PHY_MODE_11G)`를 통해 통신 규격을 고정하여 호환성을 높였습니다.
*   **절전 모드 해제**: `WiFi.setSleepMode(WIFI_NONE_SLEEP)` 설정으로 패킷 누수를 차단했습니다.

### 🧠 메모리 최적화 (The 14KB Strategy)
12.2KB 원본 데이터를 처리하기 위해 ESP8266의 가용 램(약 45KB)을 극한으로 활용했습니다.
*   **버퍼 밸런스**: SSL RX 버퍼와 MQTT 버퍼를 각각 **14,336바이트(14KB)**로 설정. 16KB 설정 시 발생하던 힙 고갈(Exception 0)을 방지하면서도 데이터 수신에 성공했습니다.
*   **JSON Filter**: `ArduinoJson`의 필터 기능을 사용하여 12KB 중 필요한 500바이트 미만의 데이터만 메모리에 남기고 즉시 폐기합니다.
*   **힙 메모리 전환**: 스택 오버플로우(`Exception 3`)를 고치기 위해 `StaticJsonDocument`를 버리고 **`DynamicJsonDocument`**를 사용하여 여유로운 힙 공간을 활용했습니다.

### 🔌 PWM 제어 및 하드웨어 테스트
MOSFET(D4184)을 이용한 LED 밝기 제어 성능을 검증했습니다.
*   **측정 데이터 (12V 공급 시)**:
    *   PWM 255 (100%): 0.37A
    *   PWM 191 (75%): 0.28A
    *   PWM 128 (50%): 163mA
    *   PWM 64 (25%): 86mA
    *   PWM 25 (10%): 41mA
*   **고주파 성능 확인**: 5,000Hz(5kHz) 환경에서도 MOSFET이 뭉개짐 없이 정밀하게 반응함을 확인했습니다. 
*   **카메라 플리커링**: 1,000Hz(1kHz) 이상에서 30fps 카메라(X1C 기본 카메라) 및 타임랩스 촬영 시 줄 생김 현상이 발생하지 않음을 검증했습니다.

## 3. 종합 평가
ESP8266은 램 용량이 매우 작아 현대적인 SSL 통신과 거대 JSON 처리에 부적합하다는 통념이 있으나, **주도면밀한 버퍼 관리**와 **필터링 기법**을 통해 충분히 안정적인 시스템 구현이 가능함을 확인하였습니다. 현재 시스템은 1kHz 이상의 주파수로 눈의 피로와 카메라 플리커링을 모두 잡은 상태로 가동 준비가 되었습니다.
