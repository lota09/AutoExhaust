# 🔋 LED 스트립 부하 측정 및 SMPS 과부하 테스트 보고서

본 문서는 AutoExhaust 2.0 조명 시스템에 사용될 LED 스트립의 실제 전력 소비량을 측정하고, 기존 SMPS의 가용 여부를 판별하기 위한 실험 기록입니다.

## 1. 실험 대상 (DUT)
*   **LED 스트립**: 9W/m 스펙, 총 길이 1.5m (이론적 소비전력: 13.5W, 12V 기준 1.125A)
*   **전원 1 (SMPS)**: 12V / 1.5A 정격 어댑터
*   **전원 2 (파워서플라이)**: 실험용 정밀 직류전원장치

## 2. 실험 결과 및 데이터

| 테스트 조건 | 전원 장치 표시 전류 | 멀티미터 측정 전류 | 비고 |
| :--- | :---: | :---: | :--- |
| **SMPS 단독** | - | **2.0A** | 정격(1.5A) 대비 133% 과부하 상태 |
| **파워서플라이 단독** | **2.0A** | - | 12V 세팅 시 정격보다 높은 전류 소모 확인 |
| **파워서플라이 + 멀티미터 직렬** | **1.7A** | **1.7A** | 멀티미터 내부 저항(Burden Voltage)에 의한 전류 감소 |

## 3. 현상 분석 및 고찰

### 🔴 스펙 대비 높은 전력 소모
*   **이론치**: 9W/m × 1.5m = 13.5W (1.125A)
*   **측정치**: 최고 24W (2.0A)
*   **분석**: LED 스트립의 실측 부하가 스펙보다 약 **77% 더 높게** 나타남. 이는 전압 강하를 고려하여 설계된 저항값이 낮거나, 실제 LED 소자의 효율 특성 차이로 보임.

### 🟡 측정 도구에 의한 오차 (1.7A vs 2.0A)
*   파워서플라이와 멀티미터를 직렬로 연결했을 때 전류가 0.3A 감소함. 
*   이는 멀티미터 전류 측정 모드에서의 **부단 전압(Burden Voltage)** 및 리드선의 저항으로 인해 회로 전체의 저항이 증가하여 실전류가 감소한 결과임. 실제 다이렉트 연결 시에는 **2.0A**가 흐르는 것으로 판단해야 함.

### ⚠️ SMPS 과부하 내구도
*   **상황**: 1.5A 정격의 SMPS가 2.0A를 출력하며 **33% 과부하** 상태로 작동함.
*   **결과**: 다행히 SMPS는 파괴되지 않고 작동을 유지함.
*   **주의**: 현재는 견디고 있으나, 장시간 사용 시 내부 부품(캐패시터, FET)의 열화로 인해 수명이 급격히 단축되거나 갑작스러운 소손(Burn-out) 가능성이 매우 높음.

## 4. 결론 및 향후 조치
1.  **전원 장치 교체 권장**: 현재 1.5A SMPS는 위험 수위임. 안전율을 고려하여 **12V / 3A 이상의 전원 어댑터**로 교체하는 것이 필수적임.
2.  **PWM 제한 적용**: 만약 현재 전원을 그대로 사용해야 한다면, 소프트웨어적으로 `ledcWrite` 값을 최대 **150~180** 정도로 제한하여 평균 소비 전류를 1.5A 이하로 억제해야 함.
3.  **발열 모니터링**: 1.5A SMPS를 사용할 경우 어댑터 탱크의 발열을 지속적으로 체크하여 플라스틱 변형이나 탄 냄새가 나는지 확인 필요.
