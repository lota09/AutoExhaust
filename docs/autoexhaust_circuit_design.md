# 🏎️ AutoExhaust 2.0 회로 설계 가이드 (ESP32-C3 SuperMini)

본 문서는 **AutoExhaust 2.0** 시스템의 하드웨어 핀 맵 정의를 다룹니다.

---

## 1. 핀 맵 정의 (GPIO Map)

| 용도 | 핀 번호 (GPIO) |
| :--- | :---: |
| **전원 측정 (ADC)** | **3** |
| **MOSFET 1 (팬)** | **4** |
| **MOSFET 2 (예비)** | **5** |
| **RGB LED - R** | **0** |
| **RGB LED - G** | **1** |
| **RGB LED - B** | **10** |

---

본 설계를 바탕으로 **'불사조'** ESP32-C3 보드의 펌웨어 개발을 지속합니다.
