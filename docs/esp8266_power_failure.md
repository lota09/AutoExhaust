# ⚡ ESP8266 (Wemos D1 R1) 전원 계통 파손 분석 보고서

## 1. 상황 (Situation)
*   **하드웨어 구성**: 
    *   메인 보드: Wemos D1 R1 (ESP8266)
    *   전원부: 24V DC 입력 → LM2596 벅 컨버터 (12V 출력 세팅)
    *   제어부: 이중 D4184 MOSFET 모듈
    *   부하: 50cm LED 스트립 (12V 구동)
*   **연결 상태**:
    *   벅 컨버터의 12V 출력이 MOSFET 모듈의 Vin에 연결됨.
    *   Wemos 보드는 전용 USB 케이블로 PC에 연결(프로그래밍/통신용).
    *   Wemos의 D6(PWM) 핀과 GND 핀이 MOSFET 모듈의 제어단에 연결됨.
*   **사고 발생**: 시스템에 24V 외부 전원을 인가하는 순간 물리적인 스파크와 함께 보드 가동 중단.

## 2. 문제 및 결과 (Problem & Result)
*   **물리적 증상**:
    *   보드 전원 인가 시 ESP8266 메인 칩 부위에서 비정상적인 발열 발생.
    *   USB 연결 시 장치 관리자에서 포트(COM)는 인식되나, 통신(Upload/Serial Monitor)은 전혀 불가능함.
    *   시리얼 모니터(74880 baud) 응답 없음.
*   **계측 진단 결과**:
    *   멀티미터 도통 테스트 시 **3.3V 단자와 GND 단자가 단락(Short)**된 것으로 판명.
    *   ESP8266 칩 내부 로직 회로가 과전압으로 인해 영구적으로 파손됨.
*   **최종 결론**: **하드웨어 사망 (Brick)**.

## 3. 원인 분석 (Root Causes)

### A. 핫 플러깅(Hot-Plugging)에 의한 서지 (핵심 원인)
*   전원이 켜진 상태에서 연결 시, 파워 서플라이 출력 커패시터에 충전된 에너지가 순간적으로 방출됨.
*   전선 인덕턴스와 급격한 전류 변화(di/dt)로 인해 수십 볼트 이상의 **링잉(Ringing) 전압** 발생.
*   이 고전압 스파이크가 벅 컨버터의 반응 속도보다 훨씬 빠르게 통과하여 회로를 타격함.

### B. MOSFET 게이트 절연 파괴
*   유입된 서지 전압이 MOSFET(D4184)의 Drain-Gate 절연막을 물리적으로 관통.
*   12V~24V 전압이 제어 신호선(D6)을 타고 거꾸로 ESP8266의 3.3V GPIO 핀으로 유입되어 칩을 태움.

## 4. 재발 방지책 (Prevention)

### 🛡️ 하드웨어 보호 회로 보강
*   **직렬 저항 추가**: MCU 신호선(D6)과 MOSFET Gate 사이에 1kΩ~10kΩ 저항을 추가하여 전압 역류 시 전류를 제한.
*   **바이패스 커패시터**: 벅 컨버터 출력단에 고주파 노이즈 차단용 0.1μF 세라믹 콘덴서(104) 병렬 연결.
*   **제너 다이오드**: MCU 전원단(3.3V)에 3.6V~3.9V 제너 다이오드를 병렬로 달아 과전압 유입 시 차단.

### 🔌 운용 절차 개선
*   **접지 우선 연결**: 외부 전원을 연결하기 전, 공통 GND 배선을 가장 먼저 확실하게 체결할 것.
*   **핫 플러깅(Hot-plugging) 주의**: 전원이 켜진 상태에서 선을 꽂는 행위를 지양하고, 스위치를 통해 전원을 투입할 것.
*   **절연 제어 고려**: 고전압/고전류 부하 제어 시 포토커플러(Optocoupler)가 내장된 모듈을 사용하여 물리적으로 신호선을 완전 분리할 것.
