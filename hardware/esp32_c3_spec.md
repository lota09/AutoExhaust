# 🦅 ESP32-C3 (RISC-V) 스펙 및 특수 기능 가이드

**"ESP8266의 완벽한 진화형이자 가성비의 제왕"**
ESP32-C3는 ESP8266과 핀 호환성을 유지하면서도, 최신 RISC-V 아키텍처와 보안 기능을 탑재한 차세대 저가형 MCU입니다.

---

## 1. 하드웨어 스펙 (Hardware Specification)

### 🧠 코어 및 메모리
*   **CPU**: 32-bit RISC-V Single Core (최대 160MHz)
    *   *비교*: ESP8266(80MHz)보다 2배 빠르고, 전력 효율이 훨씬 뛰어납니다.
*   **SRAM (램)**: **400KB** (사용자 가용 약 300KB+)
    *   *혁명*: ESP8266(80KB, 가용 40KB)의 10배에 달합니다. 14KB 버퍼 튜닝? 이젠 필요 없습니다.
*   **Flash (저장소)**: 보통 4MB (모듈에 따라 다름)
*   **ROM**: 384KB (부트로더 등 내장)

### 🔌 핀 구성 (GPIO)
*   **총 GPIO**: 22개 (모듈 형태에 따라 실제 사용 가능 핀 수는 약 13~15개)
*   **ADC (아날로그 입력)**: 2개 유닛, 총 6개 채널 (12-bit 해상도)
    *   *비교*: ESP8266(A0 1개)보다 훨씬 풍부합니다.
*   **PWM**: **LEDC (LED Control)** 하드웨어 PWM 6채널
    *   *장점*: 소프트웨어 PWM이 아니라 하드웨어 타이머를 쓰므로 CPU 부하 없이 고주파/고해상도 제어가 가능합니다. (플리커링 완전 해결)

---

## 2. 통신 규격 (Communication)

### 📡 무선 통신
*   **Wi-Fi**: 802.11 b/g/n (2.4GHz), Long Range 모드 지원.
*   **Bluetooth**: **BLE 5.0 (Bluetooth Low Energy)** 지원.
    *   *핵심*: ESP8266에는 없는 기능입니다. 스마트폰 앱과 직접 통신하거나 메시 네트워크 구성 가능.
*   **Zigbee/Matter**: **지원 안 함** (이는 C6의 영역입니다). 하지만 BLE Mesh나 ESP-NOW를 통해 우회 가능.

### ⚡ ESP-NOW (초저지연 로컬 통신)
*   **기능**: 공유기(Router) 없이 ESP 기기끼리 직접 통신하는 독자 규격.
*   **특징**: 
    *   연결 절차(Handshake)가 없어 **전원 켜고 0.1초 만에 데이터 전송** 가능.
    *   **Zigbee 대체재**: 향후 C6(마스터)를 허브로 두고, C3(슬레이브) 여러 대를 ESP-NOW로 묶으면 **간접적인 Zigbee/Matter 연동**이 가능해짐.
    *   **거리**: 개방된 공간에서 최대 200m 이상 도달.

---

## 3. C3만의 특수 기능 (Special Features)

### 🔒 보안 (Security) - "Secure Boot & Flash Encryption"
*   **RSA-3072 기반 보안 부팅**: 해킹된 펌웨어가 실행되는 것을 원천 차단.
*   **플래시 암호화**: 펌웨어를 덤프 떠도 내용을 볼 수 없게 암호화 저장. (상용 제품 수준)

### 🌡️ 내장 온도 센서
*   칩 자체의 온도를 측정하는 센서가 내장되어 있어, 과열 시 스스로 클럭을 낮추거나 알림을 보낼 수 있습니다.

### 🕰️ 초저전력 (Deep Sleep)
*   **소모 전류**: Deep Sleep 시 **5μA** (ESP8266은 20μA).
*   **RTC 메모리**: 8KB의 저전력 메모리가 있어, 잠에서 깨어나도 이전 변수 값을 기억할 수 있습니다.

### 🖱️ USB-Serial JTAG 내장
*   **편의성**: CH340 같은 USB 변환 칩 없이, C3 칩 자체가 USB 신호를 직접 처리합니다.
    *   *장점*: 별도 드라이버 설치 불필요, 고속 업로드 및 하드웨어 디버깅 가능.

## 4. AutoExhaust 2.0 적용 포인트
1.  **메모리 해방**: 12KB MQTT 패킷? 그냥 받으시면 됩니다. (400KB 램의 위엄)
2.  **하드웨어 PWM**: 팬과 LED를 CPU 간섭 없이 20kHz 이상의 고주파로 아주 부드럽게 제어할 수 있습니다.
3.  **ESP-NOW 확장성**: C3 단독으로 쓰다가, 나중에 C6를 도입하면 펌웨어 업데이트만으로 거대한 스마트홈 네트워크의 일원이 될 수 있습니다.
